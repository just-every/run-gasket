# Migration source formats

These primary references establish the source formats, not Gasket implementation status. Missing export classes must be resolved through authorized source extraction and the reconciliation in MIG-008 before a buyer cuts over.

- MaintainX publishes [organization CSV export classes](https://help.getmaintainx.com/export-organization-data), [work CSV details and date-range limits](https://help.getmaintainx.com/export-work-order-data) and [PDF procedure/comment/audit detail](https://help.getmaintainx.com/export-a-work-order-to-pdf). Attachment URLs require retrieval of originals, and omitted user/PM detail requires an authorized supplemental path.
- UpKeep documents [work CSV/PDF and PDF ZIP exports](https://help.onupkeep.com/en/articles/9736598-how-to-export-work-orders), [CSV/Excel work-history fields including File IDs](https://help.onupkeep.com/en/articles/1746947-how-to-import-or-update-work-orders-and-work-order-history), and [meter guides](https://help.onupkeep.com/en/collections/3653446-upkeep-meters). PDFs and file references do not by themselves constitute original attachment migration.
- Fiix documents [CSV/report/database ZIP export, optionally with uploaded files](https://helpdesk.fiixsoftware.com/hc/en-us/articles/5499960764052-Export-and-save-backup-data) and [entity import formats and scheduled-maintenance behavior](https://helpdesk.fiixsoftware.com/hc/en-us/articles/212108226-Data-import-overview). Source plan entitlements and schema/version determine the extraction route, never the promised Gasket end state.
- Limble documents [Excel exit exports](https://help.limblecmms.com/en/articles/3082121-will-i-keep-my-data-after-the-trial-period), [task spreadsheet/CSV downloads](https://help.limblecmms.com/en/articles/2982369-how-to-filter-and-download-tasks) and [completed-task import limitations, including files and historical stock](https://help.limblecmms.com/en/articles/3085249-how-to-bulk-import-completed-tasks). Original attachments and reading coverage need separate extraction and reconciliation.
- Tractian advertises [spreadsheet migration and maintenance capabilities](https://tractian.com/en/pricing) and publishes [integration options](https://tractian.com/en/solutions/integrations) and a [developer center](https://docs.tractian.com/). These do not establish a universal lossless outbound file format; MIG-006 requires a tenant-specific manifest and delivered extraction adapter.
